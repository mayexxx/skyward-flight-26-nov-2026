Skyward Flight is an original flight game written in this session. Fly in chase or cockpit view through ten golden rings, then return to the runway for a landing. Stalling or hitting terrain crashes the aircraft; a safe touchdown requires a slow, level approach on the runway. The screenshots are headless Chrome renders of the running game.

## Run it locally

From the repository root, run `python3 -m http.server 8080 --directory game`, then open http://localhost:8080 in a desktop browser. Use the arrow keys to fly, Shift and Ctrl to adjust throttle, and the mouse to steer; the mouse wheel also adjusts throttle. Press V to change view, P to pause, and R to restart after a landing or crash.
